# 图片混淆工具 🖼

基于 Gilbert 空间填充曲线的图片可逆混淆/解混淆工具。纯浏览器端处理，图片不上传任何服务器。

## 功能

- **混淆**：将图片像素沿 Gilbert 曲线循环平移（黄金比例偏移），生成视觉均匀的噪点混淆图
- **解混淆**：沿同一曲线反向平移，PNG 输出下像素级无损还原
- **混淆轮数**：1~10 轮可调（≥2 轮时混淆/解混淆必须使用相同轮数）
- **输出格式**：PNG（无损，可完美还原）/ JPEG（质量 0.95，压缩后仍保色）
- 支持点击选择或拖拽上传图片
- Web Worker 后台处理，大图不卡界面

## 技术栈

- 原生 HTML / CSS / JavaScript（零外部依赖）
- Gilbert 空间填充曲线（广义 Hilbert，支持任意宽高矩形）
- Web Worker（Blob URL 内联，防大图阻塞 UI）

## 算法原理

1. `gilbert2d(width, height)` 生成覆盖每个像素恰好一次的曲线路径（路径上相邻像素在二维空间也相邻）
2. 混淆 = 像素沿曲线循环平移 `offset = round((√5−1)/2 × W×H)`（黄金分割比例）
3. 解混淆 = 反向平移一次，无损还原
4. 空间填充曲线保留局部邻域结构 → 混淆图仍高度可压缩，JPEG/缩略图处理后还原效果稳定（区别于随机打乱）
