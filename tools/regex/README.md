# 正则表达式测试工具 🔬

> 实时正则匹配与高亮工具：输入正则表达式和待匹配文本，即时高亮匹配结果，并内置基础语法参考。

## 技术栈

- 纯静态 HTML + CSS + JavaScript（零外部依赖）
- 浏览器原生 JavaScript 正则引擎（ECMAScript 规范）
- 仅在浏览器端运行，无后端需求

## 功能

- **实时匹配**: 输入正则表达式即触发匹配，无需点击按钮
- **高亮显示**: 匹配到的字符串在文本框中以黄色实时高亮（双层叠加实现，保留光标与选区）
- **匹配结果列表**: 展示每一处匹配的位置区间、内容和长度
- **标志位开关**: `g` 全局 / `i` 忽略大小写 / `m` 多行 / `s` 点号匹配换行 / `u` Unicode
- **语法参考**: 页面下方内置正则基本语法速查表（元字符、字符类、量词、断言、转义等）
- **错误提示**: 正则语法错误时实时提示原因
- **一键复制/清空**: 每个文本框右上角均提供「清空」「复制」按钮

## 访问

通过 nginx 代理：`http://localhost:8001/regex/`

## 目录结构

```
tools/regex/
├── README.md
└── dist/
    └── index.html     # 构建产物（单文件应用）
```

## 开发与部署

该工具为单 HTML 文件应用，直接编辑 `dist/index.html` 后刷新即可。

修改后需更新 `nav/index.html`（如需）和 `deploy/nginx/port-8001.conf`（如需）。
